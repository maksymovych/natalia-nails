# Portfolio images

Put Nataliia's own nail photos here (JPG, PNG or WebP), then register each one in
`src/data/portfolio.ts`.

- Use descriptive filenames, e.g. `nude-almond-milky-01.webp`, `french-short-square-02.jpg`.
- Crop the original nail photo. Do not use Instagram screenshots (no app UI, likes, or captions).
- Recommended: portrait 4:5, at least 1200px on the long edge, under ~400 KB (WebP is ideal).
- Only publish photos the owner took or has permission to publish.
